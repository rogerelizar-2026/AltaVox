# 🎙️ Sistema AltaVoz

Sistema de transcrição e análise de áudio que funciona 100% localmente no seu navegador.

## 🚀 Como Iniciar (Método Simples)

### Windows
**Duplo clique em `iniciar.bat`** - Isso é tudo!

### Linux / macOS
```bash
./iniciar.sh
```

## 📋 Pré-requisito

Você precisa do **Node.js** instalado:
- Baixe em: https://nodejs.org/ (versão LTS)

## ✨ O Que o Script Automático Faz?

1. Verifica se o Node.js está instalado
2. Instala todas as dependências automaticamente (apenas na primeira vez)
3. Inicia o servidor de desenvolvimento
4. Abre o sistema no seu navegador

## ⏱️ Tempo de Inicialização

- **Primeira vez**: 2-5 minutos (instalação das dependências)
- **Próximas vezes**: 5-10 segundos

## 📖 Documentação Completa

Veja o arquivo [`COMO_INICIAR.md`](./COMO_INICIAR.md) para instruções detalhadas e perguntas frequentes.

## ⚠️ Importante

**NÃO abra o `index.html` diretamente!** Use sempre os arquivos `iniciar.bat` ou `iniciar.sh`.

---

**Funciona 100% offline após a instalação inicial!** 🎉
